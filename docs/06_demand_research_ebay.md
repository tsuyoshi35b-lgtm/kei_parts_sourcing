# 需要調査：eBay の成約データ（2026-10-22）

何に需要があり、どの商品を扱うべきかを決めるための調査。前回までの調査（`04_research_summary.md`）は掲載価格だけだったので、今回は **eBay の成約（Sold）データ**で件数と成約価格を数えた。

## 調べ方
- eBay.com の「販売済み」検索（ログイン状態）を、ブラウザ上のスクリプトで最後のページまで送り、**直近90日（2026-07-24〜10-21）に成約した出品**を数えた。同じ出品の重複は除いた
- 価格は eBay が表示した**円換算の成約価格（送料別）**。表示レートは 2026-10-22 時点
- Terapeak（eBay の公式調査ツール）は出品者ハブへの登録が必要で使えなかった。登録はアカウント設定の変更にあたるため行っていない
- 国内の仕入れ相場は Yahoo!オークションの落札相場（直近180日、ページ上部の集計値）を使った
- 部品の種類分けは、タイトルの英単語による自動分類（おおまかな目安）

### 数字の限界（必ず読む）
- 1つの出品で複数個売れた場合、1件としか数えていない可能性がある → **件数は少なめに出ている**
- eBay.com の検索には英国など米国外の出品者も含まれる。買い手の国は分からない
- 「日本所在」の絞り込みは、該当が少ないと関係の薄い出品が混ざる（ヤンマー等で米国業者が混入）。日本所在の数字は目安
- 「新品」は出品者の申告。FA の「新品」は中国の出品者による互換品・模造品を含む可能性が高い
- 90日分なので季節の偏りがありうる（除雪関連は冬に増える可能性）。年間の数字は単純に4倍した推定

### 誰が売っているか
- 出品者は約490。上位10者で46%
- 1位 **haruwws_japan（日本の出品者）：90日で270件・659万円**（年約2,600万円）。中央値21,353円、新品が約8割。アクティとサンバーが中心
- 2位 minitruckgarage（米国）：235件・727万円。3位 minitruckusa：116件
- 日本所在の出品は約900件（約4割、目安）、中央値15,501円で全体より高い
- **日本から発送しても、1件2万円前後の新品部品が月90件売れている**。D-001 で「個人向けは納期で米国在庫に勝てない」としたが、eBay では日本発送でも成り立っている実例がある

### 国内の仕入れ側（Yahoo!オークション、参考）
- 「キャリイ 純正 新品」は180日で358件、平均6,424円。ただし新品純正部品の主な仕入れ先はディーラー・部品商なので、Yahoo の相場は目安にとどまる
- eBay の中央値（1〜1.4万円、送料別）との差は、手数料・送料・関税を引くと薄い部品もある。**部品ごとに仕入れ値を確認するまで利益率は「要検証」**

## 2. FA 機器
- 市場は最大（5メーカーで年約47億円の推定）。ただし出品数が57万〜100万件以上と桁違いで、**売れる割合が1%未満**。米国の在庫業者（plc-usa-d1、plc-depot、arpimachinesales 等）と中国の出品者が中心
- 日本の相場が eBay より高い・同じものが多く、価格差が出ない：
  - キーエンス：Yahoo 平均27,386円（180日11,119件） ＞ eBay 中央値18,742円
  - Q06UDEHCPU：Yahoo 平均25,023円（60件） ＞ eBay 中央値11,861円（中国の「新品」が安値を作っている）
  - サーボアンプ MR-J4：Yahoo 平均27,893円（844件）、eBay の三菱サーボ中央値51,522円 → 差はあるが、動作確認と保証が必要
- **価格差が出るのは生産終了品**：A1SHCPU は Yahoo 平均4,463円（29件）、eBay の MELSEC A/AnS 中央値18,147円（250件）
- 結論：既定の方針（段階3で三菱 A シリーズなど生産終了品に限定）を変える理由はない。むしろ「生産終了品以外はやらない」と明確にしたほうがよい

## 3. 大工道具
- **売れる割合は高い（鑿32%、鉋24%）が、市場が小さい**（3品目で年約4,000万円の推定）
- 鑿の約8割が中古。日本の出品者が多い（鑿389件のうち日本所在256件、うち akitadogjp が166件）
- 日本国内の相場が eBay より高い：追入鑿は Yahoo 平均20,692円（180日788件）、eBay の oire nomi 中央値14,077円。中古の良品を国内で買って eBay で売る価格差はほぼない
- 前回の「田斎の10本組が豪州で2,695豪ドル・品切れ」は新品の小売価格で、eBay の成約ではほとんど出てこない（田斎の成約は90日で2件）
- 結論：中古の転売は不利。やるなら**新品を鍛冶屋・問屋から仕入れて海外の工具店に卸す形**で、eBay 以外の調査（海外工具店の在庫切れ・取扱銘柄）が必要

## 4. その他
- 顕微鏡の対物レンズ：年約1.7億円の推定、中央値2.5万円、85%が中古。日本の出品者（microscope-cameralovelove、d-space-jp）が既にいる。検品の技術が要るため、従来どおりデータ調査のみ
- MC カートリッジ：年約8,000万円の推定、中央値4.1万円、売れる割合19%。中古が中心で古物商許可が前提
- 農機部品（クボタ・ヤンマー・イセキ）：eBay ではマニュアル本が多く、需要の測定に向かない。欧州の業者向けは eBay ではなく業者への聞き取りで確かめる

## 判断の材料（提案。決定は DECISIONS.md に記録してから）
1. **軽トラ部品を主軸にする方針は、データで支持された**。需要は年約8,800件・1.5億円規模、新品が9割で古物商許可前でも扱える。重点はアクティ（HA3/HA4）とサンバー（KS3/KS4・TT1/TT2）、次にキャリイ DD51T・ハイゼット S80〜S110P
2. **追加の選択肢：eBay で新品の軽トラ部品を出品して需要を直接確かめる**。haruwws_japan の実績から、日本発送でも売れることは確認できた。業者向けの営業と並行でき、出品データがそのまま部品データベースになる。ただし D-001（個人向けはやらない）の変更になるので、決めるのはユーザー
3. FA は段階3のまま、対象を生産終了品（三菱 A シリーズ、旧型サーボ）に限定
4. 大工道具は優先度を下げる。中古の転売はやらず、新品の卸を別途調べる
5. 次に確かめること：アクティ・サンバーの売れ筋20点について、ディーラー・部品商の仕入れ値（成約価格）を取り、送料・関税・eBay 手数料を引いた利益率を出す
