# 仕入れ値と利益率の調査（2026-10-22）

`06_demand_research_ebay.md` で売れている品目について、日本での仕入れ値を調べ、eBay で直接売る場合と業者向け代行の場合の利益率を出した。

- 品目と数字：`data/margin_items.csv`
- 計算：`tools/margin_calc.py`（前提を変えて計算し直せる）
  ```
  py tools/margin_calc.py                       # 関税15%
  py tools/margin_calc.py --duty 27.5           # 関税27.5%
  py tools/margin_calc.py --oem-cost-rate 0.75  # 純正部品を定価の75%で仕入れられた場合
  ```

## 調べ方
- **売値**：eBay の成約価格（直近90日、円換算）。なるべく日本の出品者が送料無料で売った価格を使った。1〜4件しかない品目が多く、ぶれは大きい
- **仕入れ値**：Yahoo!ショッピングで品番検索した新品の最安値（税込・送料無料が多い）。中古は Yahoo!オークションの落札相場。**一般向けの小売価格なので、部品商から業者価格で買えればもっと安くなる**
- **費用**（`tools/margin_calc.py` の ASSUMPTIONS）
  - eBay 手数料：13.6%（売上税込みの額にかかる。売上税は平均7%と仮定）＋海外取引手数料1.65%＋1注文60円＋円で受け取る時の為替コスト2%（要検証） → 売上の約18%
  - 送料：日本郵便の公式料金（米国宛て）。2kg以下で長さ60cm以下は国際エアパケット（100g 1,200円〜2kg 5,190円）、それ以外は EMS（1kg 5,300円・2kg 7,900円・3kg 10,300円・5kg 15,100円）。梱包で0.2kgと150円を足した
  - 関税：日本郵便で米国に送るには関税の前払い（DDP）が必要（2026-07-24 以降、内容品2,500ドル以下）。**税率は資料で15%と27.5%に分かれていて確定できなかった**ので両方で計算。前払いの代行手数料（Zonos）は金額が分からず、1件500円と仮置き（要検証）
  - 業者向け代行：D-002 の案（部品代＋20%、最低3,000円）。受取手数料3%、まとめ発送1kgあたり1,800円（要検証）。関税は業者が払う

## 結果の要点

### 1. 純正部品を小売価格で仕入れると、ほとんど赤字
関税15%で、純正部品19品目のうち利益率10%を超えたのは2品目だけ（エンジンマウント26%、アクセルワイヤー13%）。

| 品目 | 売上 | 仕入れ（小売） | 利益 | 利益率 |
| --- | ---: | ---: | ---: | ---: |
| アクティ イグニッションコイル（純正） | 20,809 | 19,332 | -8,602 | -41% |
| アクティ 燃料ポンプ | 33,840 | 29,578 | -10,354 | -31% |
| アクティ クラッチディスク | 22,302 | 19,082 | -8,405 | -38% |
| アクティ エンジンマウント | 35,293 | 11,300 | 9,239 | 26% |
| キャリイ アクセルワイヤー | 20,975 | 8,514 | 2,751 | 13% |
| サンバー サイドブレーキケーブル左右 | 28,999 | 13,646 | 1,505 | 5% |

- eBay では、純正部品が日本の小売価格の1.0〜1.5倍で売れていることが多い。手数料（約18%）・送料・関税（15%）を引くと残らない
- 部品商から**定価の75%で仕入れられた場合**でも、黒字になるのは約半分（エンジンマウント34%、アクセルワイヤー23%、サイドブレーキケーブル17%、クランクプーリー15%、ハイゼット燃料ポンプ14%）

### 2. 利益が出るのは「国内メーカーの社外品」と「整備用のセット」
| 品目 | 売上 | 仕入れ | 利益（関税15%） | 利益率 | 関税27.5%の時 |
| --- | ---: | ---: | ---: | ---: | ---: |
| F6A ヘッドガスケット（KP 製） | 20,175 | 2,040 | 8,896 | **44%** | 32% |
| アクティ ウォーターポンプ | 35,114 | 5,280 | 13,955 | **40%** | 27% |
| サンバー タイミングベルトセット | 26,699 | 7,260 | 7,194 | **27%** | 14% |
| アクティ 排気温センサー（NAP 製） | 21,511 | 6,582 | 5,247 | **24%** | 12% |
| アクティ イグニッションコイル（日立製の同等品） | 20,809 | 9,300 | 1,430 | 7% | -6% |

- 日本の部品メーカー（KP、NAP、日立、多摩興業など）の同等品は国内で安く、eBay では3〜7倍の価格で売れている。haruwws_japan など日本の出品者が利益を出しているのはこの層と思われる
- **注意**：売値には「純正」として売れた価格が混ざっている（コイル・センサー・ガスケットの一部）。社外品として正しく書いて売った場合の価格は、別に確かめる必要がある（要検証）。社外品を純正と偽って売ることはしない
- ウォーターポンプの eBay 価格には、タイミングベルトなどとのセット品が含まれている可能性がある

### 3. 重い物は送料で赤字になる
- クラッチ3点キット（約4kg）は売上3.1〜4.0万円に対して EMS が約1.3万円かかり、**3品とも赤字（-10〜-12%）**
- eBay の割引配送（SpeedPAK など）やクーリエの契約料金なら変わる可能性がある（料金は未確認・要検証）

### 4. 業者向け代行（D-002 の料金案）
- 当方の利益は1件あたり**約2,300〜7,000円（請求額の約12〜18%）**。最低手数料3,000円が効くので、小さい部品ほど率が高い
- 業者が米国の eBay で再販した場合に粗利が出るのは、社外品・整備セット・一部の純正品（エンジンマウント33%、タイミングベルトセット36%、ウォーターポンプ52%、KP ガスケット53%）
- 純正品の多くは、業者の到着原価が eBay の成約価格を上回る。**業者が日本に頼む理由は値段ではなく「米国で手に入らない」こと**になる。営業では「手に入らない部品の探索」を前面に出す

### 5. FA 機器：全部赤字
- 三菱 MR-J2S（中古）-35%、A1S61PN（新品）-38%、HC-KFS（新品）-39%、FX2N（中古）-30%
- 日本の落札相場が eBay の成約価格とほぼ同じで、手数料・送料・関税の分だけ赤字になる。**FA は扱わない根拠になる**

### 6. 大工道具：利益が出ない
- 河清「暁」叩木彫のみ 10本組：利益率7%（関税27.5%なら赤字）
- 菊弘丸 追入鑿 10本組：-33%（国内価格16.5万円に対して eBay 成約17.1万円）
- 角利 小鉋：12%だが、利益は1個670円

## 結論（提案）
1. **軽トラ部品は「国内メーカーの社外品・整備セット」を中心にする**。純正品は、部品商の業者価格が取れた品目と、米国で手に入らない品目に限る
2. **FA は扱わない**。大工道具は保留（新品の卸の調査はしない）
3. 重い物（クラッチキット等）は、送料の安い発送手段が見つかるまで扱わない
4. 業者向け代行の料金案（20%・最低3,000円）は、当方の利益としては成り立つ。業者の利益が出ない品目では、業者に頼まれても割高になることを伝える

## 次に確かめること（優先順）
1. **米国の関税率**（自動車部品 HTS 8708 等が15%か27.5%か）。通関業者か CBP の資料で確認。利益率が10ポイント以上変わる
2. **部品商の業者価格**：大阪の部品商・ディーラー部品課に、純正部品の業者価格（定価の何%か）を聞く
3. **社外品として売った時の eBay 価格**：KP・NAP・日立などのブランド名で成約を検索し直す
4. **発送手段**：eBay の SpeedPAK・FedEx・DHL の契約料金（2kg超）
5. **消費税**：免税事業者のうちは仕入れの消費税（10%）が戻らない。課税事業者を選ぶと輸出免税で還付される。どちらが得かは税理士に確認
6. 国際エアパケットは 2027-02-01 に値上げ予定（100g 1,200円→1,680円、二次情報）。決まったら送料表を直す
