# 法令・確認事項

私（Claude）は法律の専門家ではない。最終確認は警察署（生活安全課）・税務署・行政書士・通関業者などで行う。

## 古物商許可
- 中古品（一度一般の人の手に渡った物を含む。ヤフオク・メルカリで個人から買う未使用品も古物）を仕入れて売るなら必要。新品をメーカー・部品商・ディーラーから仕入れるだけなら不要
- 「頼まれて代わりに売買する」営業も古物営業に含まれる。代行でも必要
- 輸出だけでも必要（国内で古物を買い取る行為が対象）
- 事業主体（妻）が取得する。夫の許可を妻の事業に使うのは名義貸しで違法（重い罰則）
- 申請先：営業所を管轄する警察署（大阪府公安委員会）。手数料19,000円・審査約40日が目安（申請前に要確認）
- 品目：「自動車」（軽トラ部品）、将来FAは「機械工具類」
- 営業所は自宅可（賃貸なら使用承諾書が必要な場合あり）。管理者は妻
- 許可後の義務：古物台帳の記録、一定額以上の買い取りでの本人確認（非対面の方法はルールあり。許可時に警察で確認）
- 申請中は新品部品だけで調達を始める
