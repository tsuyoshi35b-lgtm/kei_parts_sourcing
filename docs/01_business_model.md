# 事業モデル

## 一言で
海外の軽トラ輸入業者・販売店の「日本の部品調達窓口」になる。業者の顧客が必要とする部品を、車台番号から特定し、日本で仕入れ、まとめて送る。

## なぜ成り立つか
- 日本国内向けモデルの部品は日本にしかない。メーカーの海外拠点は国内向けモデルを支援しないことが多い（Kubota豪州・Yanmarはグレー輸入機への部品供給を公式に拒否）
- 業者は顧客から部品を頼まれるが、日本の仕入れ網と日本語の部品カタログを持っていない
- 業者の顧客は、日本からの部品を数週間待つことに慣れている
- 米国の軽トラは25年ルールで毎年輸入可能な年式が増え、部品を必要とする車が増え続ける

## 料金（案・要確定）
- 部品代＋手数料20%、1回の最低手数料3,000円。ドル建て
- 送料は実費（週1回のまとめ発送で下げる）。米国向けは日本製品に合計約12.5%の関税（2026年7月24日以降。出荷前に再確認）。800ドル以下の免税（デミニミス）は停止中
- 業者は自分の利益を上乗せして顧客に売るので、手数料が見えていても問題ない
- 見つからない・見積もりどおりに合わない場合は全額返金

## 採算の目安（推測・要検証）
- 注文当たり貢献利益率の計画値は25%（GPTの試算17〜30%、Claudeの試算20〜40%。Geminiの41〜47%は根拠不明のため不採用）
- 1件あたりの人の作業時間：始めは60〜90分、データが貯まれば20〜30分

## 一番の弱点と対策
- 1件ごとに手で探すと作業が注文数に比例して増える → よく頼まれる部品の番号・仕入れ先を data/parts_db.csv に記録し、2回目からは数分で見積もる
- 業者が日本の仕入れ先と直接つながる（中抜き） → 部品特定のデータと対応の早さを、相手が自前で持てない価値にする

## ウェブサイトの段階
1. 窓口サイト（今〜1か月）：事業紹介、依頼の流れ、手数料、見積もり依頼フォーム（車台番号・部品名・写真）、FAQ、会社情報、プライバシーポリシー、特定商取引法の表記。Claude Code で作ればドメイン代のみ
2. 検索向け記事（2〜6か月）：車種・型式ごとのページ。実際に扱った部品の記録から作る
3. 業者向けページ（取引先10〜30社）：型式検索、見積もり依頼、注文履歴、配送状況
4. 定価販売（売れ筋が見えたら）：消耗品キットなど価格を固定できる商品のみ

## プラットフォーム（マッチング）を今やらない理由
- 価値は「つなぐこと」ではなく「部品の特定・検品・まとめ輸出」にある
- Buyee・ZenMarket・FromJapan などの購入代行が既にある
- 一度つながると直接取引されやすい
- 仕入れ先が50社ほどに増え、自分で処理しきれなくなってから検討する
