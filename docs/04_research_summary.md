# 市場調査の要約（2026-10-21時点）

詳細は Claude Docs のレポート：https://claude.ai/artifact/So1mfqkRrnqcnv1BmtWT8s

## 探索の原則
「日本にしかない物を探すより、海外の誰かが高いお金を払ってでも解決したい問題を探す。その解決手段が日本に安く存在していれば、商売が成立する可能性がある」

## 3つのAI（Claude・GPT・Gemini）の比較
- 3つとも「日本国内仕様の機械 × 型式の照合 × 部品供給」に収束した。日本の強みは価格差ではなく「型式別の部品情報と国内の仕入れ網へのアクセス」
- どのAIも実際の成約データや仕入れの見積もりは取れていない
- Geminiの数字（利益率40%超、3か月で月商80〜100万円）は出典がなく不採用
- GPTの指摘（豪州消費者法、部品表の転載、運転資金、モノタロウの海外持ち出し制限）は採用

## 軽トラ市場の根拠
- 米国への軽トラ輸入は7,500台超（2023年の報道）。小さな輸入業者は年40〜60台を販売
- 競合：Oiwa Garage（米国倉庫に在庫、アクティ用4点キット343.88ドル）、Amayama、Megazip、minitrucks.net、KEI Import Parts、Samurai Trucks
- 個人向けの直接販売は納期で不利 → 業者向けの調達代行に切り替えた

## 欧州
- 日本の中古小型トラクターを直接輸入し部品も売る業者がある（オランダ・ハンガリー・ギリシャ）
- 豪州のグレー輸入農機の販売店は今回の検索では特定できなかった

## 他に調べて外したもの
- 融着接続機：メーカーが正規ルート外の製品を修理せず、不正販売を監視・提訴
- キーエンス・ファナックの中古：中国の業者が安く、米国の業者が2年保証つきで販売
- 盆栽道具・万年筆・釣具：日本の出品者が多く価格競争
